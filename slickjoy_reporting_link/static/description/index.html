SlickJoy Reporting

Ask your Odoo data a question in plain words and get a live chart back, with the exact read-only query behind it. Click any bar to narrow the chart and list the Odoo records underneath it.

Why teams use it

  • Plain-language questions. Type what you want to know. No SQL, no report builder, no spreadsheet export.
  • Every number traces back. Each chart keeps its query and links to the records it came from.
  • Pages that refresh themselves. Save a page of charts and schedule its refresh. If a refresh fails, the page says so.
  • Read-only by design. SlickJoy Reporting only reads from Odoo. It has no write path.
  • One flat price. $30 per month per organization, with your whole team included and no per-seat fees.

How it works

  1. Install this module. Open SlickJoy Reporting from the main menu.
  2. Create your account and connect your Odoo database with an Odoo API key.
  3. Ask a question and save the chart to a page your team can open every morning.

Your data

Installing this module does not send any Odoo data to SlickJoy. Data is sent only after you connect a SlickJoy Reporting account and run a question. Credentials are encrypted at rest and never reach a browser.

Requirements

  • Odoo 14.0 through 20.0 (Community or Enterprise).
  • A SlickJoy Reporting account: $30 per month per organization.
