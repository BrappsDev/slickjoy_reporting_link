SlickJoy Reporting for Odoo

Ask your Odoo data a question in plain words and get a live chart back, with the exact read-only query behind it. Click any bar to narrow the chart and list the Odoo records underneath.

What it does

  • Plain-language questions. No SQL, no report builder, no export to a spreadsheet.
  • Every number traces back. Each chart keeps its query and links to the records it came from.
  • Scheduled pages. Save a page of charts and refresh it on a schedule.
  • Read-only by design. SlickJoy Reporting reads from Odoo and never writes to it.
  • One flat price. $30 per month per organization, with your whole team included.

Getting started

Install this module, then open SlickJoy Reporting in the main menu and choose Get SlickJoy Reporting. Create your account, connect your Odoo database with an Odoo API key, and save your first chart.

Requirements

  • Odoo 14.0 (Community or Enterprise).
  • A SlickJoy Reporting account, $30 per month per organization.

Installing this module does not send any Odoo data to SlickJoy. Data is sent only after you connect a SlickJoy Reporting account and run a question.
